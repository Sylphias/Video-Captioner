<objective>
Turn the Fastify backend from a hardcoded LAN dev server into an Electron-hostable child process: environment-overridable runtime config (data root, media root, port, host per D-11/D-12), production frontend serving via @fastify/static (D-04), and the D-03 process-lifecycle guarantees (graceful-then-tree-kill child cleanup + orphan watchdog). All edits keep `just dev` / `just backend` working unmodified via dev-mode fallbacks.

Purpose: The Electron shell (Plan 05) cannot spawn, health-gate, or cleanly shut down the backend until these hooks exist. This is the foundation the whole port stands on.
Output: An env-configurable backend entry point + a reusable child-process registry that tree-kills descendants on exit.
</objective>

Create `packages/backend/src/services/childRegistry.ts` exporting: `registerChild(pid: number)`, `unregisterChild(pid: number)`, and `killAll(signal?: string): Promise<void>` that tree-kills every registered pid (wrapping tree-kill's callback in a Promise, resolving once all callbacks return, with a per-pid best-effort try/catch). Keep an internal Set<number> of live pids. This is the single cleanup point Plan 02 will register spawned python/render-worker pids into. In `index.ts`, add a `process.on('SIGTERM', ...)` and `process.on('SIGINT', ...)` handler that: (1) awaits `killAll('SIGKILL')` from childRegistry, (2) awaits `fastify.close()`, (3) calls `process.exit(0)` — guarded by a boolean so double-signals don't re-enter. Also add an orphan watchdog: read `process.env.PARENT_PID`; if set, `setInterval` every 2s checks the parent is alive via `process.kill(parentPid, 0)` inside try/catch — on ESRCH (parent gone) run the same shutdown sequence (D-03: backend self-exits if Electron vanishes). Skip the watchdog entirely when PARENT_PID is unset (dev mode).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Electron main → backend child | Config (paths, port, parent pid) crosses via env at spawn |
| backend → OS process tree | Backend spawns python/ffmpeg/render-worker descendants that must be reaped |
| network → backend | Only 127.0.0.1 after D-12; no remote/LAN clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Denial of Service | Orphaned ffmpeg/python after quit (Pitfall 4) | high | mitigate | childRegistry.killAll() tree-kills all descendants on SIGTERM/SIGINT and on orphan-watchdog trigger (Task 3) |
| T-15-02 | Information Disclosure | Server bound to 0.0.0.0 exposing app on LAN | medium | mitigate | Bind 127.0.0.1 by default per D-12 (Task 1); LAN binding intentionally dropped |
| T-15-03 | Elevation of Privilege | @fastify/static path traversal serving files outside dist | low | mitigate | @fastify/static confines to configured root; not-found handler only returns the fixed index.html, never a user-supplied path (Task 2) |
