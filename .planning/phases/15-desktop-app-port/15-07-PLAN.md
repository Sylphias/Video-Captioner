<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frontend → /api/settings | Localhost HTTP writes the HF token + media root |
| settings.json at rest | Bearer token persisted on disk under userData |
| renderer → preload chooseFolder | Sole IPC channel returns a chosen directory path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-71 | Information Disclosure | HF token stored plaintext in settings.json | medium | mitigate | Stored under %APPDATA% protected by the Windows user-profile ACL (single-user local app); GET /api/settings never returns the raw token; safeStorage encryption recorded as follow-up hardening (Task 1) |
| T-15-72 | Input Validation | Malformed/non-writable media-root path saved, breaking later writes | medium | mitigate | PUT /api/settings validates the directory exists and is writable before saving (Task 1, RESEARCH V5) |
| T-15-73 | Information Disclosure | Token echoed back to the client and visible in devtools | low | mitigate | GET returns only hasToken boolean + mediaRoot, never the token value (Task 1) |
| T-15-74 | Elevation of Privilege | Preload exposing more than chooseFolder | low | mitigate | contextBridge exposes only chooseFolder (Plan 05); no additional IPC added here |
| T-15-SC | Tampering | (no new package installs in this plan) | low | accept | No new dependencies added |
</threat_model>
