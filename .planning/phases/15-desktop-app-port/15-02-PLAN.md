<objective>
Parameterize every place the backend hard-codes an external binary path so the packaged Windows app can inject them, and register spawned children for tree-kill cleanup: the Python venv (D-07), FFmpeg/FFprobe (D-13), and the Remotion prebuilt-bundle branch for packaged mode (Pattern 2). All changes fall back to current dev values so `just dev` is unaffected.

Purpose: Without these, the packaged backend would look for `.venv/bin/python3`, a PATH ffmpeg, and re-run webpack `bundle()` from inside asar (all broken on the shipped Windows app).
Output: Env-driven binary resolution + childRegistry wiring across all spawn sites.
</objective>
